# Build the APK free with GitHub Actions

1. Create a free GitHub account if needed.
2. Create a new empty repository named `MuscleCoach`.
3. Upload the full contents of this folder, including the hidden `.github` folder.
4. Open the repository and select **Actions**.
5. Open **Build Muscle Coach APK** and select **Run workflow**.
6. When the build finishes, open the completed workflow.
7. Download the artifact named **Muscle-Coach-APK**.
8. Extract it to obtain `app-debug.apk`.
9. Transfer the APK to the Android phone and install it.

Android may ask you to permit installation from the browser or file manager used to open the APK.
