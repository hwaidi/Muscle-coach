# Muscle Coach – Android MVP

This is the first native Android version of Muscle Coach.

## Included
- Five workout days
- Current weights from the latest plan
- Warm-up for Day 1
- Set-by-set repetition entry
- New achieved weight
- Notes for pain, technique and fatigue
- Automatic Keep Weight / Increase Weight status
- Finish Workout button
- Android share sheet for sending a structured workout report to ChatGPT without an API

## Open in Android Studio
1. Install the latest Android Studio.
2. Extract the ZIP.
3. Open the `MuscleCoach` folder.
4. Allow Gradle to sync and download dependencies.
5. Connect an Android phone with USB debugging enabled, or use an emulator.
6. Press Run.

## Current limitation
This MVP keeps entered values while the screen remains open. Persistent local history with Room/DataStore is planned for the next version.
